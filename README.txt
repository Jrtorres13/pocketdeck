POCKETDECK - turn a spare phone into a Stream Deck for your PC
==============================================================

INSTALL ON THE PC (Windows 10/11, about 1 minute)
1. Unzip this folder anywhere.
2. Double-click Install.bat
   (If Windows says "protected your PC": More info > Run anyway.)
3. Click Yes when Windows asks for permission (lets the phone connect).
4. A page opens with a QR code and a 6-digit PIN.

CONNECT THE PHONE (iPhone or Android)
1. Phone on the same Wi-Fi as the PC.
2. Scan the QR code with the phone camera. Done.
   (Or type the address shown into the phone browser, then the PIN.)
3. Add it to the home screen so it opens full screen:
   iPhone: Safari > Share > Add to Home Screen
   Android: Chrome > menu > Add to Home screen

USING IT
- Tap a key = run it. Hold a key = its long-press action (if set).
- Swipe left/right = switch pages. Folders open with a back arrow.
- Pencil = edit mode. Tap a key to edit, drag to move.
- Gear = settings: grid size, pages, ready-made pages, backup.
- Edit on the PC too: tray icon > Open deck editor (easier typing,
  and Record captures hotkeys from your keyboard).

KEY TYPES
Hotkey, Open app/file, Website, Type text, Media, Volume & mic,
App volume, Audio device, Soundboard, Brightness, Window, Mouse, Dial, Live info
(shows mute state live), System (lock, sleep, screenshot...),
Run command, Multi-action (steps + waits), Toggle, Page, Folder.

MAKE IT YOURS
- Edit a key > Icon: search 1,400+ icons, use the app's real icon,
  a website logo, emoji, or your own picture.
- Edit a key > Look: light color, icon color, icon size, solid or backlit.
- Gear > Look: colorway (Ember, Deep red, Pure black, Light) and key shape.

NEW IN 1.2 (Stream Deck features)
- Tap, double-tap, hold: edit a key > Tap, double-tap, hold.
- Dials: drag across a dial key to turn it (volume, app volume, brightness).
- Live keys: clock, timer, stopwatch, counter, CPU, memory, battery, weather.
- Soundboard, app volume, switch speakers/headset, window snapping, mouse.
- Pages can follow the app you are using: Gear > Pages > "Open with app".
- Try Gear > Add a ready-made page > Mixer (dials) or Windows and PC.

TRAY ICON (bottom-right near the clock)
Open editor, Connect a phone, Pause all buttons, Start with Windows,
Unpair all phones, Quit.

PHONE CAN'T CONNECT?
- Same Wi-Fi on both (not guest Wi-Fi).
- Windows: Settings > Network > Wi-Fi > your network > Private.
- Run Install.bat again and click Yes on the permission prompt.

PRIVACY + SAFETY
- Works only on your home network. Nothing goes to the internet.
- Only phones that entered your PIN can press keys.
- Keys and pairings are saved in %LOCALAPPDATA%\PocketDeck\data

UPDATE: unzip the new version and run Install.bat again. Keys stay.
REMOVE: run Uninstall.bat.
