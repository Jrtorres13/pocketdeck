# PocketDeck features

## PC side
- Tray app, starts at sign-in, built on install with Windows' own C# compiler (no Node/.NET install)
- Local Wi-Fi server, PIN pairing, per-phone tokens, lockout after 5 wrong PINs
- Pause all buttons, unpair all, single instance

## Key actions
- Hotkey (combos + chords like `ctrl+k, ctrl+c`), with keyboard recorder on PC
- Open app / file / folder / URI, with Start Menu app picker
- Website, Type text (+Enter), Run command
- Media keys, real volume control (set / step) with live % badge
- Speaker + mic mute that turn red when muted (live from Windows)
- System: lock, screenshot, show desktop, task manager, screen off, sleep, sign out, restart, shut down (with confirm)
- Multi-action with waits, Toggle (2 actions + 2 looks), long-press action

## Deck
- Pages (swipe), folders, 6 to 32 keys, rotates with phone
- Ready-made pages: Video calls, Streaming (OBS), Editing, Coding
- Edits sync live between phone and PC
- Keep screen awake, haptic tap, backup/import

## Look (v1.1 redesign)
- New "Kiln" design: near-black, cream type, ember accent, backlit keycaps
- 4 colorways: Ember, Deep red, Pure black, Light
- Key shape (rounded, square, circle) and style (backlit, solid)

## Fully customizable icons (v1.1)
- 1,400+ icons with search ("mute", "camera", "spotify"...)
- Real app icon pulled from the PC, or a website's logo
- Emoji, your own image, or no icon
- Per key: light color (12), icon color (auto or any), icon size 60-140%, backlit or solid

## Stream Deck features (v1.2)
- Tap, double-tap and hold: 3 actions per key
- Dial keys: drag to turn PC volume, app volume, brightness, tracks, scroll, zoom, or custom
- Pages follow the app in front on the PC (Settings > Pages)
- App volume mixer per app (Spotify, Discord...) with live % and mute
- Switch speakers / headphones / mic
- Laptop screen brightness
- Window tools: snap, maximize, minimize, next screen, keep on top, close, desktops
- Mouse: click, double, right, middle, scroll
- Soundboard: send a sound from the phone, plays on the PC, tap again to stop
- Open app: running light, switch to it, close, force quit
- Live keys: clock, timer, stopwatch, counter, CPU, memory, battery, weather
- Animated GIF icons
- New ready-made pages: Mixer (dials), Windows and PC
