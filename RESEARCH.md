# Stream Deck research (Nov 2026) → PocketDeck 1.2

## What Stream Deck has, and PocketDeck now
| Stream Deck | PocketDeck 1.2 |
|---|---|
| Key Logic: press / double press / hold (v7.0) | Tap, double-tap, hold on any key |
| Stream Deck + dials and touch strip | Dial keys: drag across a key to turn it |
| Smart profiles (switch when an app is in front) | Pages follow the app in front on the PC |
| Open app: running light, long-press to close / force quit (v7.0) | Running light + Open / Switch to it / Close / Force quit |
| Volume Controller plugin (per-app volume) | App volume built in, live % and mute state |
| Window Mover plugin | Window actions: snap, maximize, next screen, keep on top, desktops |
| Weather plugin (v7.0) | Weather key |
| Soundboard | Soundboard: upload a sound from the phone, plays on the PC |
| BarRaider Win Tools / SuperMacro | Mouse clicks + scroll, audio device switching |
| Clock, timer, counter plugins | Clock, timer, stopwatch, counter keys |
| Animated GIF icons | GIF icons under 400 KB |
| Folders, multi-actions, profiles, hotkeys, text, website, media | Already in 1.0 |

## What Stream Deck is missing (PocketDeck has it)
- Free with no limits. Stream Deck Mobile free tier = 6 keys, Pro = $2.99/mo for 64 keys.
- Works on Android and iPhone, nothing to install on the phone.
- Per-app volume, window tools, PC stats, brightness: built in, no plugins.
- Live CPU / memory / battery keys.
- Laptop screen brightness keys and dial.
- Swipe between pages.

## Not built (ideas for later)
- OBS WebSocket (scene and recording state on keys).
- Plugin marketplace, MCP / voice control (Stream Deck 7.4).
- Native phone app.
